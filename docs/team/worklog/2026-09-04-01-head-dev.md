### 2026-09-04 | head-dev | 2h

Four things the founder reported. Three were real, one was not what it looked like.

- **Fish Legal alerts crashed the page.** Genuine bug, and a nasty one: the page asked the
  browser for its saved alerts on every render, and got a brand-new list each time. React
  compares those lists by identity, saw "changed" every single time, and re-rendered
  forever until it gave up and showed "This page couldn't load". Fixed by handing back the
  same list until the stored data actually changes. The page opens now.
- **Opening a record from today's calendar.** Reproduced. A normal catch opened fine — the
  broken one was a quick mark you had not finished yet. Tapping it dumped you on the whole
  log list to find it again yourself, which is indistinguishable from the tap doing
  nothing. It now opens that exact mark's "what was it?" sheet.
- **Today's limits.** Not broken, but fair to call it broken: it only listed fish you had
  already kept, so until you kept something it was an empty page. You could not use it to
  answer "how many of these am I allowed?" — which is the question people open it with,
  usually holding the fish. It now lists all sixteen limit lines, with anything you have
  kept sorted to the top so a live count is never buried.
- **Lunar data.** It turned out the app already records the moon on every catch — but only
  when it had a GPS fix. The code even said in a comment that the moon's phase is the same
  everywhere on Earth, and then threw it away anyway when there was no fix. So every shore
  catch, every catch logged before the fix arrived, and every backfilled one lost its moon
  for no reason. Now computed from the time alone. The sun still needs a position, because
  it genuinely does.
- Also made the record read like a person wrote it: "Waxing gibbous · 78% lit" instead of
  a bare percentage. The name is worked out at display time rather than stored, because the
  rule in this project is that the log keeps raw measurements and nothing derived.
- Checks: tripwires clean, no lint errors, 603 tests, production build green. Every fix was
  reproduced in a real browser first and confirmed in the same browser after.

  catch-record-view.tsx, fish-log.tsx, calendar/day-view.tsx, astro/moon.ts
