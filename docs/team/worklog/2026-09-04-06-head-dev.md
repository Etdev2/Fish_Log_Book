### 2026-09-04 | head-dev | 2h

- Tide stations, both halves: you can now choose one, and the app fetches real predictions
  from NOAA instead of drawing the same cached sample forever.
- Thirty-four stations, both coasts plus the Gulf, Alaska and Hawaii, grouped by area in a
  plain dropdown in Settings next to the region setting.
- The chart now asks NOAA for whichever station you picked. What comes back is saved on
  this device, so the tide you looked up in the marina is still there when the signal is
  not. A saved copy less than twelve hours old is used without spending signal on a
  refetch.
- The badge on the station sheet used to say "cached prediction" no matter what. It now
  says which of three things you are actually looking at: live from NOAA, saved on this
  device (and whether it is old), or the bundled sample.
- The rule I built everything around: the bundled sample belongs to Newport Bay and to no
  other station. Pick Boston with no signal and no saved copy and the screen says "no
  predictions loaded for Boston" and offers to change station. It never draws one
  station's curve under another station's name. A confident wrong tide is the worst thing
  this feature could do.
- Two honest limitations. First, the machine I work on cannot reach NOAA, so the fetching
  code is written against their documented API and the recorded shape of an earlier real
  fetch, but has not been run against the live service. Second, for the same reason the
  station ids could not be checked against NOAA's list. Both are written at the top of the
  files concerned, and the design makes a wrong id visible rather than silent.
- Found and fixed a real bug while wiring it: the chart's sun and daylight calculations
  were not being redone when the station changed, so switching coasts would have kept the
  old station's sunrise. The linter caught it.
- Also had to split the screen in two. Everything in it assumed there was always tide data,
  which was true when the only source was a sample that is never empty. Now a station can
  legitimately have nothing, so the shell decides and the chart only ever receives real
  data.
- Checked in a browser: picked Boston, got the honest empty state; back to Newport, got the
  full chart.
- Checks: tripwires clean, no lint errors, 633 tests, production build green.

  queries/noaa-tides.ts, queries/tide-cache.ts, queries/use-tide-series.ts,
