- "When I add a white seabass it does not subtract from today's limits." Reproduced, and
  the cause is a gap between two things that are each working as designed.
- The limits screen counts fish you kept. The fast way to log a catch asks for the species
  and nothing else — you only get asked kept-or-released if you open the details. So a
  quickly logged fish has no answer, is not counted, and nothing on the page says why.
- That silence is the dangerous direction for a screen whose job is keeping someone legal:
  it makes the box look emptier than it is.
- The page now says so. Any fish logged today without an answer appears in its own block
  at the top: "1 fish not counted yet". Each one has a Kept and a Released button right
  there, because it is a one-bit answer and the angler is usually holding the fish.
  Tapping Kept updates the count immediately and the block disappears.
- Making them open the record and re-save would have been five taps for one bit. Added a
  small single-field update in the store for it — the same shape as the existing favourite
  toggle, and deliberately not the save path, so it cannot disturb anything else on the
  catch.
- This keeps the page honest in the way it already claimed to be: it says a species with
  no rule is "never dropped, never called unlimited", and an unanswered fish was being
  quietly dropped.
- Verified end to end in a browser: logged a white seabass the fast way, saw "0 of 3
  retained" with the warning, tapped Kept once, saw "1 of 3 retained" and the warning gone.
