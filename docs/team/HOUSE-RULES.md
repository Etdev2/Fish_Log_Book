# House Rules

Shared by every agent. Read once, at the start of your task. Do not copy this file's
contents into other files — link to it.

## 1. The team is horizontal

There is no chain of command for *ideas*. Anyone may challenge anyone, in any field.
A UX objection to a database schema is valid. A biostatistician's objection to a button
label is valid.

There IS a chain of command for *decisions*:

- Scope / "are we building this at all" -> CEO
- Sequencing / "what happens this week" -> COO
- Code structure / "where does this file live" -> Architect
- Merge to `main` -> Head Developer

Disagree, state it once in the channel, then commit to the decision.

## 2. Next.js 16 is not the Next.js you remember

Before writing app code, read the relevant page under `node_modules/next/dist/docs/`.
Do not write App Router code from memory. This overrides your training data.

## 3. Git

- Never commit to `main`. Branch: `<role>/<short-slug>` e.g. `ux/catch-form-a11y`.
- One concern per branch. Small PRs merge; big PRs rot.
- PR body = what changed, why, how it was checked. Three bullets are enough.
- Head Developer merges. Nobody merges their own PR.
- Never commit `.env.local`, keys, or a real user's coordinates.
- `AGENTS.md` is regenerated by `next dev`. If it shows up dirty, commit it with your
  work — do not revert it, do not fight it.

## 4. Definition of done

`npm run build` passes. `npm run lint` passes. No new TypeScript errors.
You have looked at the thing in a browser, or you say plainly that you have not.

## 5. The channel

`docs/team/CHANNEL.md`. Append at the bottom. Use it when you find something *another
role* needs — not to narrate your own work.

```
### 2026-08-27 | biostat -> ux
NOAA tide data is 6-minute intervals. A chart with 240 points/day will crawl on an
old iPhone. Bucket to hourly before it hits the client.
```

Reply by appending underneath. Do not delete other people's entries.

## 6. The worklog

`docs/team/WORKLOG.md`. Append one block per session, at the bottom. Plain English —
written so a person who does not code can read it and know what happened.

```
### 2026-08-27 | head-dev | 40m
- Catch form crashed when the date was left empty. Fixed.
- Turned on the type checker in CI so this class of bug stops at the PR.
- Files: src/features/catches/form.tsx, .github/workflows/ci.yml
- Next: nobody has tested the form on a real phone yet.
```

Rules: no jargon, no ticket numbers, say the honest time, say what is still broken.

## 7. Token discipline (CFO enforces)

- Do not read a file you do not need. Do not re-read a file you just wrote.
- Search with `grep`/`rg` for the line, then read around it. Do not cat 900-line files.
- Facts that outlive the session go in git, not in a long conversation. Git is free
  to store and cheap to grep; conversation context is paid for on every single turn.
- `CLAUDE.md` and `AGENTS.md` load into *every* session. Keep them tiny. Point to
  paths, do not `@`-import docs.
- Finish in your own lane. Handing work sideways re-reads the whole project.
